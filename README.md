# AgentMaze

Autonomous security laboratory for discovering emergent attack paths in AI agent systems.

## Project Goal

AgentMaze simulates autonomous AI agents, tools, permissions, memory, and interactions inside a controlled environment to discover and analyze multi-step security attack paths.

## Current Status

Day 1 — Agent simulation and capability permission model.

## Current Features

- Agent simulation
- Capability-based permissions
- Tool execution
- Permission enforcement
- Controlled simulation environment

## Tech Stack

- Cybersecurity
- Graph-based Attack Analysis
